IG + AS

A constant is a promise

TICKET_PRICE = 12
tickets = 3
total = TICKET_PRICE * tickets
The ticket count changes between sales. The price is fixed for this version of the program.
One named rate avoids scattered “magic numbers”. When next term’s price changes, update one definition.
Python will allow a later TICKET_PRICE = 15. Uppercase is a convention: keep your own promise.
📝 IN THE EXAMA constant’s value does not change during execution. Explain a maintenance benefit in the given context.
🏛 IN REALITYSome languages enforce constants. Plain uppercase names in Python do not.

Names help the next reader

Use names that explain their role: ticket_price and ticket_count are easy to distinguish.
Conventional short names can be clear: x and y for coordinates, i for an index. A single letter is not automatically wrong.
Explain intent in comments. “# add one” repeats the code; “# count this accepted ticket” explains its purpose.
📝 IN THE EXAMMeaningful identifiers and useful comments support maintainability. They are not a fixed automatic mark per line.
🏛 IN REALITYType comments here are a learning scaffold. Python style commonly uses snake_case; consistent naming helps the next reader.
